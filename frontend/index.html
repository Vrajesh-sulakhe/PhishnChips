    How Phish&Chips Stays Safe (Blast Radius Zero)

    1. Process Isolation Untrusted code runs strictly inside a throwaway container; the host VM and user device are completely insulated.
    2. Secret Hygiene No API keys, credentials, or private paths ever enter the sandbox container runtime.
    3. Resource Limits Hard Linux cgroups cap execution to 1 CPU, 1 GB RAM, 256 PIDs, with a 45s hard wall-clock kill switch.
    4. Lifecycle Discipline Every container is purged immediately after scan completion. No state persists.
