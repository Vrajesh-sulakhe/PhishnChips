    Platform Overview

    What is Phish&Chips?

    Phish&Chips is an autonomous, agentic cybersecurity system built for Track 01 (Blast Radius Zero) of the Vultr Agent Rush Hackathon. It replaces passive URL scanners with active, containment-first runtime sandboxes.

    💥

    The Phishing Crisis

    Modern cyber attacks use dynamic Single Page Applications (SPAs), OTP interceptors, and automated drive-by downloads. Static domain blocklists fail because fraudulent links only live for a few hours.

    🛡️

    Blast Radius Zero

    Rather than checking DNS records, Phish&Chips fires up a throwaway, hardware-throttled Linux container within milliseconds. Kernel-level iptables cut off host networks and cloud metadata access.

    🧠

    Pattern B & Vultr AI

    When login forms are detected, human-in-the-loop authorization gates inject synthetic decoy canaries to track exfiltration routes. Vultr Serverless Inference (Llama-3 Vision) synthesizes verdicts in real-time.

    Blast Radius Zero Guarantees

    Four layers of mathematically enforced security boundaries

    🔒

    1. Process Isolation

    Untrusted code runs strictly inside a throwaway container; the host VM and user device are completely insulated.

    🛡️

    2. Secret Hygiene

    No API keys, credentials, or private paths ever enter the sandbox container runtime.

    ⚡

    3. Resource Limits

    Hard Linux cgroups cap execution to 1 CPU, 1 GB RAM, 256 PIDs, with a 45s hard wall-clock kill switch.

    🍟

    4. Lifecycle Discipline

    Every container is purged immediately after scan completion. No state persists.
