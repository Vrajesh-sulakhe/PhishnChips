Core Philosophy

Blast Radius Zero: Containment as the Product

Four non-negotiable guarantees enforced on every single detonation.

🔒 1. Process Stripping

Unprivileged user (runner, UID 10001). All Linux capabilities stripped via --cap-drop=ALL, privilege escalation blocked with --security-opt=no-new-privileges, and root filesystem mounted --read-only.

🛡️ 2. Secret & Host Hygiene

Zero API keys, cloud tokens, or host files ever cross the container boundary. The Docker socket is never mounted. The container exists solely to browse and report.

⚡ 3. Hard Cgroup Resource Bounds

Strict resource clamps: --cpus=1, --memory=1g, --pids-limit=256. Hard 45-second wall-clock orchestrator kill switch stops runaway loops or crypto miners.

🔥 4. Total Ephemerality

Every sandbox container is immediately destroyed after telemetry extraction via --rm and finally blocks. Guaranteed zero persistence: "Phish fried. Sandbox destroyed."
