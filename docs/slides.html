Smart Agent Behaviors

The "Fake Decoy" Trick & The Code X-Ray

How the AI tricks scammers and inspects their hidden code without risking your data.

🎭 Pattern B: The "Fake Decoy" Trick (Human Gate)

Phase 1: Finding the Trap (Passive Look)
The browser loads the page and spots username & password boxes. Instead of typing blindly, the agent immediately pauses.

The Human Safety Gate
A pop-up asks you: "I detected a password harvester. May I feed it fake decoy credentials to see where they send the data?" You remain in full control.

Phase 2: Feeding the Decoy
If approved, the browser types fake dummy data (test_canary_user) and clicks Submit. It tracks where the scammer exfiltrates the password, exposing their hidden server without risking any real user's data!

🔬 REA Engine: The Code X-Ray

Static Analysis by Default
Every single scan automatically x-rays the website's background code (JavaScript, WebAssembly, and dropped files).

Measuring Code Randomness (Entropy)
Normal code looks readable. Malware code is often heavily scrambled or encrypted to hide from antivirus. Our engine calculates an 'entropy' score: high entropy means hidden danger.

Mapping Scammer Tricks (MITRE ATT&CK)
Translates technical tricks into clear threat categories: 'Input Capture' (keystroke stealing), 'Exfiltration' (sending data to hacker servers), or 'Malicious File'.
